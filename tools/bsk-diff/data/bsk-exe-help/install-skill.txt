Install the browser-skill agent skill into local agent harnesses

Usage: bsk.exe install-skill [OPTIONS]

Options:
  -H, --harness <HARNESS>          Harness id to install into (repeatable). Run with `--list` to see ids
      --all                        Install into every harness detected on this machine
      --context <CONTEXT>          Control context returned by cooperate sync. Required for shared-tab actions
      --depends-on <DEPENDS_ON>    Legacy strict-policy decision regions. Target policy uses --expect instead
      --list                       Show harness paths and detection status without installing
      --observation <OBSERVATION>  Explicit observation ID for visual or untargeted actions; never inferred from cached state
  -y, --yes                        Non-interactive mode (required for scripts when not specifying harnesses explicitly)
      --expect <EXPECT>            JSON array of target facts to check before input: [{"target":"@e1","field":"text","equals":"Save"}]
      --source <PATH>              Path to a skill directory (with SKILL.md and resources), or a single SKILL.md
      --force                      Overwrite an existing `browser-skill` skill installation
      --json                       Emit machine-readable JSON output (when meaningful)
      --mcp                        Also configure the BrowserSkill MCP server for Codex, Claude Code or Cursor
      --quiet                      Suppress informational output
  -v, --verbose...                 Increase log verbosity (`-v` debug, `-vv` trace)
  -h, --help                       Print help
