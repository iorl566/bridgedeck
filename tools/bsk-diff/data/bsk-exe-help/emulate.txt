Emulate a mobile device environment (viewport, UA, touch) on a tab

Usage: bsk.exe emulate [OPTIONS]

Options:
      --session <SESSION>
          Session id (omit to resolve via caller scope)
      --context <CONTEXT>
          Control context returned by cooperate sync. Required for shared-tab actions
      --scope <SCOPE>
          Explicit caller scope name for multi-agent isolation
      --depends-on <DEPENDS_ON>
          Legacy strict-policy decision regions. Target policy uses --expect instead
      --tab-id <TAB_ID>
          Target tab. Defaults to the Agent Window's active tab
      --device <DEVICE>
          Built-in device preset (iphone-14, iphone-14-pro-max, iphone-se, pixel-7, galaxy-s23, ipad-mini, galaxy-tab-s8). Manual flags override individual preset fields
      --observation <OBSERVATION>
          Explicit observation ID for visual or untargeted actions; never inferred from cached state
      --expect <EXPECT>
          JSON array of target facts to check before input: [{"target":"@e1","field":"text","equals":"Save"}]
      --width <WIDTH>
          Viewport width in CSS pixels (requires --height unless --device supplies it)
      --height <HEIGHT>
          Viewport height in CSS pixels (requires --width unless --device supplies it)
      --json
          Emit machine-readable JSON output (when meaningful)
      --dpr <DPR>
          Device pixel ratio (requires --width/--height without --device)
      --quiet
          Suppress informational output
      --mobile
          Emulate a mobile viewport (requires --width/--height without --device)
  -v, --verbose...
          Increase log verbosity (`-v` debug, `-vv` trace)
      --no-mobile
          Turn a preset's mobile viewport flag back off
      --ua <UA>
          User-Agent override string
      --accept-language <ACCEPT_LANGUAGE>
          Accept-Language header override (requires --ua or --device)
      --touch
          Enable touch emulation (combines with --device or manual flags)
      --no-touch
          Turn a preset's touch emulation back off
      --max-touch-points <MAX_TOUCH_POINTS>
          Touch points reported while touch emulation is enabled (implies --touch)
      --off
          Clear all emulation overrides and restore the tab's real environment. Mutually exclusive with every other option
  -h, --help
          Print help
