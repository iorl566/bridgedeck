Fill a text input, textarea, or contenteditable editor root

Usage: bsk.exe fill [OPTIONS] --value <VALUE> [TARGET]

Arguments:
  [TARGET]  Snapshot ref (`@e3`, `e3`) or CSS selector. Optional when `--ref`/`--selector` is used

Options:
      --value <VALUE>              Text to type into the element
      --context <CONTEXT>          Control context returned by cooperate sync. Required for shared-tab actions
      --ref <REF>
      --depends-on <DEPENDS_ON>    Legacy strict-policy decision regions. Target policy uses --expect instead
      --selector <SELECTOR>
      --observation <OBSERVATION>  Explicit observation ID for visual or untargeted actions; never inferred from cached state
      --session <SESSION>
      --expect <EXPECT>            JSON array of target facts to check before input: [{"target":"@e1","field":"text","equals":"Save"}]
      --scope <SCOPE>
      --json                       Emit machine-readable JSON output (when meaningful)
      --tab-id <TAB_ID>
      --no-clear                   Skip the default "wipe the field first" pass
      --quiet                      Suppress informational output
      --timeout <TIMEOUT>          [default: 30s]
  -v, --verbose...                 Increase log verbosity (`-v` debug, `-vv` trace)
  -h, --help                       Print help
