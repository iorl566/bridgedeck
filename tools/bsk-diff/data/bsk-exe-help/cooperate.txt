Cooperate with a person on the same browser tab

Usage: bsk.exe cooperate [OPTIONS] <ACTION>

Arguments:
  <ACTION>
          Synchronize default shared control, inspect ownership, or wait for hand-back. Enable remains an optional alias for synchronization and task-tab binding

          [possible values: enable, status, sync, wait]

Options:
      --session <SESSION>


      --context <CONTEXT>
          Control context returned by cooperate sync. Required for shared-tab actions

      --scope <SCOPE>


      --depends-on <DEPENDS_ON>
          Legacy strict-policy decision regions. Target policy uses --expect instead

      --policy <POLICY>
          Session control policy (sync/enable only). Auto preserves an existing choice or starts target control

          [possible values: auto, strict, target]

      --observation <OBSERVATION>
          Explicit observation ID for visual or untargeted actions; never inferred from cached state

      --tab-id <TAB_ID>


      --expect <EXPECT>
          JSON array of target facts to check before input: [{"target":"@e1","field":"text","equals":"Save"}]

      --timeout-ms <TIMEOUT_MS>
          Bounded wait, up to 25 seconds. Waiting never holds the action queue

      --json
          Emit machine-readable JSON output (when meaningful)

      --max-tokens <MAX_TOKENS>


      --match-text <MATCH_TEXT>
          Fold only plain numbered fallback buttons outside literal-match windows (repeatable, sync only).

          Only stateless `button "item N"` lines may be omitted. Keeps business text, named/stateful controls and complete forms/dialogs. Use `bsk view <saved.json> --find <text>` for text search. Changes CLI presentation only; refs and guards are unchanged.

      --quiet
          Suppress informational output

      --context-lines <CONTEXT_LINES>
          Keep numbered fallback buttons within this many lines before/after each match

  -v, --verbose...
          Increase log verbosity (`-v` debug, `-vv` trace)

      --save-full <SAVE_FULL>
          Save the unfiltered reply to a new local JSON file before presenting it (sync only)

      --baseline <BASELINE>
          Saved unfiltered predecessor; its VOM is reused for an exact unchanged reply and patched for an exact text delta. Save the merged reply with --save-full to keep the chain

      --settle
          Recover transient read-only sync refusals with wait then sync, at most 3 attempts. Never repeats a browser action. A human hold returns without a context

  -h, --help
          Print help (see a summary with '-h')
