browser-skill — drive your browser from AI agents

Usage: bsk.exe [OPTIONS] <COMMAND>

Commands:
  open                 Start or reuse a scoped session, navigate to a URL, and return a settled VOM snapshot
  sync                 Synchronize the active tab's VOM snapshot and refresh its short context alias
  close                Stop the active session, return borrowed tabs, and detach the debugger immediately
  ledger               Inspect or manually reconcile pending `UNKNOWN` actions in the Intent WAL
  dialog               Decide native JavaScript dialogs (alert, confirm, prompt, beforeunload)
  operation            Retrieve or cancel the original operation suspended by a native dialog
  cooperate            Cooperate with a person on the same browser tab
  step                 Execute one action, await a known condition, and return synchronized state
  plan                 Run several decided actions in order, stop at the first failure, and return synchronized state
  recipe               Replay a saved, reviewed flow without a model turn per step
  view                 Read a saved observation locally, without refreshing refs or contacting the browser
  daemon               Manage the local `bsk` daemon process
  status               Show daemon status
  doctor               Run diagnostics + repair hints
  install-skill        Install the browser-skill agent skill into local agent harnesses
  update               Check for and install bsk CLI updates
  logs                 Print (and optionally follow) the daemon log file
  mcp                  Serve BrowserSkill tools to MCP clients over stdio
  session              Session lifecycle
  browsers             List connected browsers
  tab                  Tab management commands
  window               Agent Window management commands
  emulate              Emulate a mobile device environment (viewport, UA, touch) on a tab
  screenshot           Capture a PNG of the viewport, full page, DOM element or Canvas region
  snapshot             Produce an indented aria-snapshot with @eN refs
  observe              Produce a semantic VOM observation with perception probes
  console              Read buffered console/log/exception messages
  network              Read buffered network responses / failures
  debug                Opt-in website debugging: requests, page context, and recording export
  get-html             Dump raw HTML for a tab or a snapshot ref
  read                 Read current DOM fields safely across unrelated animation. No JavaScript
  extract              Extract loaded tables/lists with column definitions and source metadata
  navigate             Navigate the Agent Window's tab to a URL
  navigate-back        Step back in history one entry
  navigate-forward     Step forward in history one entry
  reload               Reload the current tab
  click                Click a snapshot ref or CSS selector
  hover                Hover a snapshot ref or CSS selector
  wheel                Dispatch a native mouse-wheel event at the viewport centre or an element
  drag                 Drag an element to another element or by a relative offset
  scroll-to            Scroll a snapshot ref or CSS selector into the visible viewport
  focus                Focus a snapshot ref or CSS selector
  blur                 Remove focus from a snapshot ref or CSS selector
  fill                 Fill a text input, textarea, or contenteditable editor root
  press                Dispatch a keyboard key combo
  select               Set `<select>` option values by `value` attribute
  upload               Upload files through a page file input or explicit drop target
  download             Capture one browser download and write it to a local path
  evaluate             Execute arbitrary JavaScript (strict observation required). For passive DOM data use read/extract
  wait-for-navigation  Wait for a page-lifecycle event
  wait-for-element     Wait until an element becomes visible / hidden / attached / detached
  wait-ms              Sleep for a duration on the daemon side
  request-help         Ask the human to complete an in-page step (captcha / login / confirm)
  record               Record user actions into a semantic `trace.json` textbook for LLMs
  video                Record a task tab to MP4 and save it to an explicit destination
  help                 Print this message or the help of the given subcommand(s)

Options:
      --scope <SCOPE>              Explicit caller scope name for multi-agent session isolation
      --context <CONTEXT>          Control context returned by cooperate sync. Required for shared-tab actions
      --depends-on <DEPENDS_ON>    Legacy strict-policy decision regions. Target policy uses --expect instead
      --observation <OBSERVATION>  Explicit observation ID for visual or untargeted actions; never inferred from cached state
      --expect <EXPECT>            JSON array of target facts to check before input: [{"target":"@e1","field":"text","equals":"Save"}]
      --json                       Emit machine-readable JSON output (when meaningful)
      --quiet                      Suppress informational output
  -v, --verbose...                 Increase log verbosity (`-v` debug, `-vv` trace)
  -h, --help                       Print help
  -V, --version                    Print version
