Read current DOM fields safely across unrelated animation. No JavaScript

Usage: bsk.exe read [OPTIONS]

Options:
      --session <SESSION>
      --context <CONTEXT>          Control context returned by cooperate sync. Required for shared-tab actions
      --scope <SCOPE>
      --depends-on <DEPENDS_ON>    Legacy strict-policy decision regions. Target policy uses --expect instead
      --tab-id <TAB_ID>
      --observation <OBSERVATION>  Explicit observation ID for visual or untargeted actions; never inferred from cached state
      --selector <SELECTOR>        CSS selector in the main document. Reads all matches, up to max-nodes
      --expect <EXPECT>            JSON array of target facts to check before input: [{"target":"@e1","field":"text","equals":"Save"}]
      --ref <REF>                  Exact observed DOM ref, including iframe/shadow nodes. Never retargeted
      --fields-json <FIELDS_JSON>  JSON array of {key, read, optional selector/attribute}. Reads: text, attribute, value, checked, exists. Default: [{"key":"text","read":"text"}]. No JavaScript
      --json                       Emit machine-readable JSON output (when meaningful)
      --max-nodes <MAX_NODES>
      --quiet                      Suppress informational output
      --max-bytes <MAX_BYTES>
  -v, --verbose...                 Increase log verbosity (`-v` debug, `-vv` trace)
      --timeout-ms <TIMEOUT_MS>
  -h, --help                       Print help
