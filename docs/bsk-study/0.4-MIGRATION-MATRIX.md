## 2. What is real

- Remote CDP over headless Edge, called from CLI and DSH host tools.
- Real actions: click, hover, scroll, wheel, fill, select, upload, download, press, drag.
- Real observation: VOM, AX, semantic graph, extract, read, network, console, snapshot, full-page screenshot.
- Addressable refs: `domPath` -> `backendNodeId` for all late nodes via batched resolution; snapshot emits `[bnN]`; ref click/fill/press/select roundtrips are in the stage gate.
- Real TraceV3 recording with auto-hooked click/fill/hover/select/press/drag steps.
- Live eval runner with 120 real fixture cases (parallel, ~70s); trusted in-page overlay clicks; VOM observe pagination; extract retained targets; MCP stdio server (8 tools); 0.3 CLI session runner; real MJPEG AVI.
- Stage gate with remote real check: 15/15.
- 0.3.0 full E2E 212/212, unit 1025/1025, preflight PASS, dist untouched.

## 3. Major gaps

1. `tool.video`: real MJPEG AVI; no audio/mp4/transcoding.
2. `tool.cooperate`: no human shared-control channel.
3. `request_help` always times out; recording is real but drag is recorded as a click step.
4. Session/tab_borrow are metadata-only; host calls do not persist browser state.
5. OOPIF parent-page Input remains browser-limited.
6. Collaboration capture-control is a state machine, not connected to a real overlay.
7. Eval corpus has 120 live cases; broader browser corpus still small.
8. DSH default executor is wired, but only the stateless remote subset is covered.
9. Linux/macOS and native fsync are unverified.
10. DSH process-level restart is untested; only plugin reload is tested.

## 4. Honest conclusion

0.4 has real remote runtime and broad protocol method coverage, but it is not BSK-parity. Do not claim full parity or completion. External platform claims stay blocked until verified.
