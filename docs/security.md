# 安全

BridgeDeck 的默认边界是“本机、已授权标签页、显式会话”。

## 连接边界

- daemon 默认只监听回环地址。
- 远端必须显式开启，并使用 WSS 与配对 token。
- 本机未配对连接可用但显示身份警告；严格模式只接受已配对连接。
- 配对码有时效、可撤销；撤销会断开已连接实例。

## 标签页边界

- Agent 默认在自己的 Agent Window 工作。
- 借用用户标签页需要确认（设置可关闭），结束后归还。
- 关闭标签页、会话结束或断连会清理该标签页上的 CDP、录制与借用状态。
- 无痕会话需要浏览器扩展权限；不可用时明确报错，不静默降级。

## 凭据

- 配对 token、本地凭据只存扩展本地。
- 不写入日志、截图、调试导出或审计导出。
- 调试请求头/响应体在采集阶段脱敏；密码字段按敏感规则处理。
- 远程凭据到期/被撤销后不能自动跳过验证。

## 数据落点

| 数据 | 位置 |
| --- | --- |
| 设置/凭据 | 扩展本地存储 |
| 调试证据 | 扩展 IndexedDB |
| 视频 | 扩展 IndexedDB + OPFS |
| 长截图 | 扩展存储 + 用户指定文件 |
| 审计 | 本机 daemon 目录 |
| MCP/CLI 输出 | 标准输出或用户指定文件 |

## 输入可信度

- 普通点击/输入默认走页面事件；需要绕过反自动化检测时显式 `--trusted`，由 CDP 生成可信事件。
- 页面内的脚本无法直接伪造 `isTrusted` 事件；协作采集据此区分人/Agent。
- 对话框、上传、下载等敏感动作都有超时与明确失败，不会无限等待。

## 隐私

- 不上传浏览数据到远端服务。
- 远程连接只传命令与回包；截图、视频、审计默认留在本机。
- 扩展商店隐私说明见 `extension/PRIVACY.md`。
