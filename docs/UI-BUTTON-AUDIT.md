# UI 按钮审计

最后更新：2026-11-16。版本：0.1.3。

## 结论

静态审计共 **80 个按钮**：

- **77 个有明确事件路径**（click / submit / change / data-page 委托 / inline onclick）；
- **3 个是信息图标**，通过 hover/focus + `aria-describedby` 展示说明，不执行页面动作；
- **0 个未绑定事件**。

动态生成的列表按钮（录制列表的查看 / 导出 / 删除）由 `ops.js` 在创建时绑定，不包含在这 80 个静态按钮内。

## 三个信息图标

弹出页的“控制提示 / 借用确认 / 人工协助”旁边的 `?` 按钮：

- 不是操作按钮；
- 鼠标悬停或键盘聚焦时显示 `role="tooltip"` 说明；
- 不执行设置修改。

## 已修正的静默按钮

- 弹窗“修改浏览器名称”在会话进行中原本点击无反应；现在会 **禁用并显示原因提示**，避免看起来像坏按钮。

## 复跑

```sh
node tools/ui-button-audit.mjs
```

有未绑定按钮时退出码为 1。

## 与 BSK 0.5.0 的逻辑对齐

- 功能入口卡片 → 内嵌视图，返回键按“主界面 → 功能列表 → 功能子页”回退，和 BSK 的 `setView` 一致；
- 信息图标使用 `aria-describedby` + hover/focus tooltip，不执行动作，和 BSK `SettingInfo` 一致；
- 设置开关保存期间禁用，失败时在弹窗显示错误，和 BSK `InteractionSettings` 的 `loaded/saving` 逻辑一致；
- 当前调试任务点击后打开调试页并带上 `tabId`，和 BSK `CurrentTasks` 打开 debug 页一致；
- 会话进行中禁用“修改浏览器名称”，避免点击无反应。

## 运行时覆盖

真实 Edge/Chrome E2E 覆盖：

- 弹窗开关、配对、快捷功能入口、内嵌面板（29b）；
- 长截图页真实截图（31）；
- 操作录制页开始/停止（32）；
- 调试页采集、规则、性能、重放（33–33d）；
- 审计页读取（34）；
- 视频页录制（35）。

其余导出、清空、保存、丢弃等按钮由静态绑定审计确认路径存在；破坏性操作不建议在自动验收里无条件点击。
