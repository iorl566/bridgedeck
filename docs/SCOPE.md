# 源码等价范围

最后更新：v0.1（多智能体并行补齐后）

## 目标

以 **逐文件源码等价** 为验收标准，对齐全部 149 个对照文件：

- 允许引入 React、mediabunny 等必要依赖，或内置（vendoring）到项目中
- 允许按对照实现重写模块
- 不设“核心路径等价”豁免，不以文件存在、仅导入通过、类型文件占位作为完成
- 注释与文档不得出现第三方平台名或产品名

## 当前判定

| 维度 | 现状 |
| --- | --- |
| 文件边界 | 149/149 对照文件均有对应镜像（另有 3 个辅助镜像，共 152） |
| 行数覆盖 | 28958 / 28826（约 100.5%，差额为两个辅助模块） |
| 行为验证 | 单测 793、E2E 131、CLI 139、插件 21、MCP 9 全绿 |
| 完成状态 | **未完成**，仍存在真实行为差异与文档契约差异 |

## 判定规则

- **源码等价**：公开 API、分支、错误语义、消息契约、状态机与对照一致；允许因 JS 无类型而用 JSDoc 表达契约
- **不算完成**：仅有同名文件、仅导入成功、仅补注释、用行为近似替代可验证分支
- **验收证据**：定向单测、全量单测、CLI、插件、MCP、发布检查、真实浏览器 E2E

## 范围外

无。此前列出的 UI 浮层、调试 hook、视频 worker 等均已建立镜像；仍需继续补齐其行为差异，而不是排除。
