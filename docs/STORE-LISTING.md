# 商店提交信息（浏览器扩展商店）

## 基本信息

- 名称：BridgeDeck
- 短名称：BridgeDeck
- 版本：0.1.1
- 类别：生产力 / 开发者工具
- 语言：中文（简体）

## 简短描述（≤132 字符）

让本机命令行 AI Agent 在你已登录的浏览器里读页面、填表、截图、调试；默认只连本机 daemon。

## 详细描述

BridgeDeck 把本机浏览器变成 Agent 的工作区：读取页面结构、点击/填表、导出表格、截图与长截图、录制标签页、调试请求，并在需要时请你接管或协助。

- 默认只连接 127.0.0.1 上的本机 daemon，不经过云端
- 用户标签页需要显式借用；可随时暂停/收回控制
- 支持 iframe/shadow DOM、原生对话框、上传下载、反爬场景的可信输入
- 视频/录制/审计默认关闭或需显式开始
- 快捷功能全部在弹窗内嵌：操作审计、长截图、视频录制、网站调试、操作录制
- 无遥测、无广告、无远程代码
