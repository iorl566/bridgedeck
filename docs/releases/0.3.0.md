# BridgeDeck 0.3.0

0.3.0 完成全面对标版本：完整 RefKey/CDP、OOPIF、VOM 视觉、Cooperation authority、Record per-document、Capture/Video/Debug 证据、27-case 真实浏览器 eval。

## 核心

- **RefKey/CDP**：主文档 ref 自动 backendNodeId，CDP `DOM.resolveNode`。
- **OOPIF**：同源嵌套 + 真正跨源 `Page.getFrameTree`/`DOM.getFrameOwner`。
- **VOM**：L1/L2 layers、`visualObjects`、`visualRefs`、`visualRegions`、`stableRef`、revision-bound cursor、tokenEstimate。
- **Cooperation**：FrameState、2-rAF suppression、authority generation/revision、stale generation 拒绝。
- **Record**：per-document Port、documentId/frameUrl/boundary。
- **Capture/Video/Debug**：长截图下载、capture manifest 索引、视频 IndexedDB chunks + recover、debug journal/archive store。
- **Action Receipt**：写动作成功/失败都带 receipt；replay boundary 拒绝跨 document/frame/revision 回放。
- **Eval**：27-case 真实 Edge corpus + tri-state oracle + Windows Edge CI。
- **协议**：method catalog（effect/feature/receipt）覆盖全部方法。
