# BridgeDeck 0.1.6

0.1.6 把“真实浏览器里的输入”校正为默认原生输入；GitHub 发布，Edge 0.1.3 不变。

## 输入可信度

- `click` / `fill` / `press` / `drag` / `hover` 默认走 CDP 原生输入，页面看到 `isTrusted=true`。
- `--synthetic` 显式降级为页面内合成事件（更快，但页面可识别为 `isTrusted=false`）。
- `select` 仍是程序化选中 + `input/change`（与浏览器对 select 的常见处理一致）。
- 原生输入不可用时自动回退合成路径，并在结果里保留 `trusted` 标记。
- 本机实测：默认 click/fill → `isTrusted=true`；`--synthetic` → `isTrusted=false`。

## 其他

- 页面内容、扩展浮层、CDP 附着仍是可检测面；不引入指纹补丁、反检测分支或验证码求解。
- 上一轮 0.1.5 的页面策略、配对码、候选动作/自愈、敏感数据、域名策略、性能 insight、recipe 块全部保留。

## 边界

- 真实浏览器 + 用户登录态 + 人工接管是基线，不承诺绕过第三方风控。
- 验证码仍走识别、`request-help`、人工完成后继续。
