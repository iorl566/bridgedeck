# BridgeDeck 0.3.3

> 2026-11-27 发布。0.3.2 的热修复。

## 修复

- `bridge step` 在 0.3.2 里因懒加载包装漏了 `cmdStep` 而报 `TypeError: planCommands.cmdStep is not a function`；0.3.3 已修复。
- `navigate` 单测跟进 `domcontentloaded` + `wait-for-navigation` 的新行为。

## 说明

- 扩展代码与 0.3.2 相同（仅版本号更新），商店仍以 0.3.2 为准。
- 其余性能与行为变更同 0.3.2。
