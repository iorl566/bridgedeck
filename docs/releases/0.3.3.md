# BridgeDeck 0.3.3

> 2026-11-28 发布。0.3.2 的缺陷修复版。

## 修复

- **视频录制**：`video start` 后校验确实产生帧/分片；后台/最小化标签页不再“启动成功但随后查不到录制”，而是直接返回清晰错误（请把标签页切到前台可见后重试）。
- **`bridge --version --json`**：不再被当成未知选项，返回 `{"ok":true,"result":{"version":"0.3.3"}}`。
- **`open --reuse-window`**：注册 flag；复用现有 Agent 窗口并新开标签页，不再抢占已占用 tab，也不再卡 30 秒导航等待。
- **`plan --steps-file`**：兼容 Windows 常见的 UTF-8 BOM。
- **参数错误 JSON 契约**：`--json` 下解析失败也返回单行 JSON。
- **`video status/save`**：对“刚结束、仍在封装”的录制给出约 3 秒宽限，减少 E_NOT_FOUND 误报。
- **`help --json`**：明确返回 `E_ARG_CONFLICT` JSON，不再输出纯文本。

## 验证

- CLI selftest 404/404；视频相关 E2E 过滤用例 14/14；全量 E2E 222 项（含视频录制/恢复）。
- 商店扩展版本 0.3.3，功能与 0.3.2 相同，仅修复上述问题。
