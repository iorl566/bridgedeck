# BridgeDeck 0.1.8

本版修复 0.1.7 借用标签页确认链路的可见性、通知回落与跨标签页路由问题。

## 修复

- 借用前先激活目标标签页并聚焦其窗口，避免确认条注入后台标签页后用户看不到。
- 拒绝借用 Agent 窗口内的标签页。
- `tab.borrow` 不再被会话标签页守卫误拦截；`tab.close/select/borrow/return` 恢复正确传递 `--session`。
- service worker 直接创建借用/协助系统通知，不再依赖不会回到自身的 `runtime.sendMessage`。
- 借用确认超时从 30 秒调整为 60 秒；CLI 等待窗口同步为 75 秒。
- 借用允许/拒绝/超时后清理系统通知和确认条；修复清理错误的 `__bb_human_banner` ID。
- 确认文案改为“临时接管”，不再暗示把标签页移入工作区。
- daemon 为每个 tab 维护借用 reservation：同一 tab 被其他会话占用时返回 `E_BORROW_CONFLICT`；会话停止、tab 关闭、归还或 daemon 恢复时释放/重建。
- 多会话同时借用同一 tab：第一个会话独占确认与提交，第二个立即冲突，不会出现两个确认条互相覆盖。
- 借用确认改为双通道：目标标签在前台时显示模态确认；目标在后台时在**当前活动标签**显示 Toast，不抢前台；多个后台借用请求可在右下角堆叠。
- 接管浮层补齐 `role="region"`、状态 `aria-live`、按钮 `type="button"`、最小化后焦点迁移与 `aria-expanded`。
- 停止任务改为 3 秒内二次确认；第二次点击后按钮禁用并显示停止中。
- 帮助浮层改为 closed shadow，补 `role="dialog"`、折叠 `aria-expanded` 和按钮 `type="button"`。
- 借用确认对话框补齐 `role="dialog"` / `aria-modal`、Tab 焦点陷阱、Escape 拒绝和关闭后焦点恢复；按钮显式 `type="button"`。
- 借用/协助系统通知按当前 UI 语言本地化；借用通知按钮顺序统一为 Allow / Deny，与处理逻辑一致。
- 内容浮层统一设计 token（`src/overlay-theme.js`）并支持深色模式：借用模态、借用 Toast、Help、Takeover 共用同一套颜色/阴影/边框，跟随系统主题，也可用 `document.documentElement[data-bb-theme]` 强制。
- 新增真实 Chromium DOM 组件测试（借用/Toast/Help/Takeover/深色），用 `new Function(fn.toString())` 重建发布版浮层函数，验证序列化后无模块作用域泄漏。
- Popup 自测覆盖版本偏差提示、本地认证徽标（已配对/未配对/跳过/需要配对）与复制升级命令；复制失败自动回退 `execCommand` 并给出反馈。
- 清理历史死协议与失效测试：删除 `help-bridge`、`overlay-bridge`、`overlay-interrupt-client`、`overlay-version` 及引用已删 `cooperation-capture.js` 的三个 selftest；input passthrough / control blocker 明确不做，接管浮层保持非阻塞。
- 借用 Toast 不再额外发系统通知：系统通知会停在右下角盖住页面 Toast（本机 Edge 实测）；现在只有模态确认发系统通知，真机 UIA 复核只剩页面 Toast。
- 运行时/参考镜像分层：132 个参考模块物理迁移到 `reference/extension-mirror/`，构建只打包 120 个运行时 JS + 资源；参考测试移到 `tests/reference/`，新增运行时可达性门禁和解压包验证。
- 新增协作输入层第一版：manifest content script `content/cooperation.js` 提供可选点击/滚动锁和脱敏 `cooperation.read`；`src/cooperation.js` 在 Agent 输入前发 passthrough（5s TTL），暂停/收起浮层立即解锁。默认关闭，popup/options 可开启；与 bsk 的 ControlInputBlocker 一致，只拦指针/滚动，不拦键盘。
- `cooperate sync` 返回新增 `cooperation` 字段（字段/媒体/焦点/文本尾部，敏感字段脱敏）；CLI 人读输出增加 `cooperation: fields=… media=… editing=… focus=… human=…`。
- 协作活动归因：content script 记录可信 pointer/key/input/change/scroll/focus 活动（`lastHumanAt`/`lastKind`/`recent`）；Agent passthrough 期间及结束后 500ms 宽限期不计入人类活动，修复 Agent 点击 focus 被误判为“现在由你操作”。录制开始/结束清 passthrough 租约。
- `--browser` 选择器补齐同名歧义拒绝：多个实例同名时返回新登记的 `E_BROWSER_AMBIGUOUS`，要求改用 instanceId；新增 [browser-profiles](browser-profiles.md)。
- 远程 server 模式第一版：`bridge daemon start --mode server --listen 0.0.0.0 --public-url wss://…/ws --tls-pfx …`；daemon `pair.create` 使用公开 URL，`/health` 返回 bind/publicUrl；新增 [remote-server](remote-server.md)。
- 远程设备凭据持久化：远程配对成功后写入 `devices.json`（0600），daemon 重启后同 token 仍可重连；`pair devices` 展示已记住设备，`pair revoke <deviceId|code>` 删除并断开连接。新增 `pair create --scope read|control`（read 只能被动读）和 `pair renew <deviceId>`（轮换 token，旧 token/旧配对码立即失效，当前连接断开）。
- 录制/手动浮层接入共享浮层 token：跟随 `data-bb-theme` / `prefers-color-scheme`，浅色/深色都用 `--bb-surface`/`--bb-fg`/`--bb-shadow-strong`；`manual-overlay.js` 独立成模块，DOM 测试覆盖。
- i18n 覆盖审计：popup/options 的 96 条静态中文文本/属性全部有英文词条；新增 `tests/unit/i18n-coverage.test.mjs`。语言选择扩到 zh/zh-TW/en/ja/ko/de/es/fr/it/pt；8 个附加语言共 251 条 UI 词条全部人工翻译（BSK 0.5.0 术语对齐）；`i18n-coverage-report` 显示所有 `ui/*.html` 静态中文缺口为 0；新增 `locale-pack` 与 `translation-quality` 测试；内容浮层另用 54 条语义键 × 8 语言包，Borrow/Toast/Help/Takeover/Record/Manual 以及系统借用/协助通知均已本地化；`OVERLAY_DOM_OK:12` 验证日语浮层不再回退中文/英文。真机日文设置页截图 [options-ja.png](assets/ui/options-ja.png)，缺口报告 [I18N-COVERAGE.md](I18N-COVERAGE.md)。
- 新增标签页预览/聚焦页 `ui/preview.html`：`bridge ui --page preview --query tabId=<id>`，页面截取目标标签页、显示标题/URL，支持刷新和“聚焦标签页”；截图只在本扩展页面显示，不上传。证据 [preview-page.png](assets/ui/preview-page.png)。
- 新增远程 viewer：`/preview` 页面、`/preview/meta`、`/preview/shot` PNG、`/preview/click`、`/preview/key`、`/preview/focus`；真机返回 41KB PNG，点击 `#submit-btn` 触发页面结果，按键/聚焦 `{"ok":true}`，错误 token 401；read scope 点击/按键 403。
- 发布预检 `tools/release-preflight.mjs` + [release-signing.md](release-signing.md)：检查制品存在/哈希/版本混合/签名；0.1.7 制品已归档到 `dist/archive-0.1.7/`，`release.json` 只含 9 个 0.1.8 制品（darwin/linux/win portable、CLI bundle、DSH plugin、extension、Setup exe）；当前唯一预检阻塞是 `missing signature`。
- 协作状态补 `revision`/`mode`：`cooperate sync` 的 `cooperation` 现在返回 `mode`（idle/ready/acting/human/editing）和单调递增 `revision`；passthrough 期间为 `acting`，可信人输入为 `human`/`editing`。CLI 摘要增加 `mode=`、`rev=`。
- 接管浮层可见时，成功的 click/click-point/click-backend/hover 会在目标坐标显示 2s `Agent` 环标记（`target-marker.js`，跟随 light/dark token，pointer-events:none）。
