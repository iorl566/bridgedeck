# BridgeDeck 0.1.9

本版完成 Sprint A 安全脊柱，并把真实 Edge E2E 拉到 **148/148，0 跳过**。

## 修复

- Agent 输入不再被误判为人手导致会话自动暂停；
- `handback` 同步解除 daemon 暂停；
- `fill --no-clear` 正确追加而非替换；
- popup `coopState` 空值不再误显示 `COOP:fail`；
- tab 级借用预留：并发 `session.start --tab` 不会双借；
- 输入前等待两帧并复采样可见性；
- closed-shadow 焦点判定；焦点未落目标时不再盲目 `insertText`；
- replaced target 在动作前替换时 **fail closed**，不重放点击；
- record 结束恢复 takeover；record 事件按 Agent 命令窗口归因；
- iframe ref 使用 canonical frame identity + frame-local 点击；
- 协议生成物与错误效果同步。
