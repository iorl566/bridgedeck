# BridgeDeck 0.3.2

> 2026-11-27 发布。

## 性能

- CLI 冷启动（module-body）**93ms → 57ms**，端到端 `--version` 约 86ms。
- `extract table` 端到端 **231ms → 140ms**（daemon RPC 仅 13–17ms）。
- `open --reuse-window`：复用已存在的 Agent Window，open 从 ~860ms 降到 **~283ms**。
- `plan --fast`：5 步批量 **443–455ms**（默认模式 median 528ms）；daemon 侧 RPC 301ms。
- MCP 常驻进程热调用 **16–36ms/次**。
- 性能实测数据保存在内部基准记录（不随仓库发布）。

## 兼容与行为

- `bridge navigate` / `bridge open` 默认在 `domcontentloaded` 返回，重页面不再卡 60s；需要整页加载用 `--wait-until load`。
- ref 失效默认自动重观察一次（`--heal=false` 关闭）。
- `click --accept-dialog`：一步式接受原生确认框并取回原结果。
- `screenshot` 失败带 `data.reason=capture|write`。
- `plan` 新增 `observeAfter=false`（CLI `--fast`），跳过收尾同步观察；扩展默认行为不变。

## 验证

- 单元 5,060/5,060；CLI selftest 404/404；E2E 8/8；真实网站对比 23/23（BridgeDeck 侧）。
