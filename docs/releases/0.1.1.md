# 0.1.1

首个可分发版本。

## 变更

- 弹窗快捷功能全部改为内嵌面板：操作审计、长截图、视频录制、网站调试、操作录制。
- 弹窗保留完整功能页入口；主界面连接设置、自动化设置与任务列表保持同一布局。
- 长截图支持自动/手动/可见区域；视频录制支持 MP4 分片恢复、保存、清理。
- 调试支持请求、控制台、页面、性能、重复请求、规则与重放。
- 本地配对、严格模式、远程 WSS 与凭据轮换。
- CLI、MCP server、DSH 插件三套 Agent 接口。
- 文档按用户文档与内部验证分层重写。

## 安装

- 安装器：`BridgeDeckSetup-0.1.0.exe`
- 扩展包：`BridgeDeck-extension-0.1.0.zip`

扩展安装：打开浏览器扩展管理页 → 开发者模式 → 加载已解压扩展，或从商店安装。
