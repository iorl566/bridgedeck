# BridgeDeck 0.3.4

> 2026-11-28 发布。0.3.3 之后的兼容性与易用性更新。

## 新增/改进

- `request-help` 支持多目标高亮：`--target '#a,#b'`（最多 8 个，第一个为主目标）。
- `emulate` 支持 `--max-touch-points N`（默认 5），并可用 `--off` 等价 `--reset`。
- 指针/键盘动作补齐参数：`click/hover --modifiers`、`wheel --modifiers`、`press --modifiers/--hold-ms`。
- `open --snapshot` 等价 `--observe`；`debug start --run-id` 作为 `--name` 同义。
- `network` 不带子命令时默认读取当前缓冲，不再强制先 start。
- 新增 `--error-style compat`：兼容一套 15 个粗粒度 snake_case 错误码（默认仍输出 `E_*` 细粒度码）。

## 验证

- CLI selftest 404/404；全量 E2E 222/222；overlay DOM selftest 13 OK。
- 扩展版本 0.3.4，功能与 0.3.3 相同，仅上述改进。
