# BridgeDeck 0.3.1

> 2026-11-27 发布。

## 亮点

- **弹窗与页面版式**：统一品牌头与面包屑、宽页面布局、更大标题与留白；快捷功能标题与卡片对齐修正。
- **协议/CLI 兼容层**：`step --action/--params`、27 个错误码别名、4 个兼容 RPC、read/extract/drag/wheel/upload/record/debug 等字段对齐全。
- **浮层无障碍**：新增「无障碍浮层」设置，开启后使用 open shadow DOM 并标注 `role`/`aria-live`，默认仍为 closed。
- **录制交接**：`bridge record start --blocking --out trace` 阻塞到结束并导出 `trace.json + states/`，支持 `--purpose`/`--redact-values`/`--trace-version`。
- **构建瘦身**：o200k 词表改用前缀压缩二进制，扩展包约 **2.99 MB**（较上一版约 -18%）。
- **发布链路**：9 个制品 + 生产 Ed25519 签名清单 + SHA256SUMS，GitHub Release 已发布。

## 安装

- Edge 扩展：从 [Microsoft Edge 加载项](https://microsoftedge.microsoft.com/addons/detail/ieflpefpmlmmlfgmpfakaglhgmcbcnig) 安装（商店审核可能略有滞后）。
- 手动安装：下载 `BridgeDeck-extension-0.3.1.zip` 解压后在 `edge://extensions` 加载。
- Windows：`BridgeDeckSetup-0.3.1.exe`（当前为项目自签名，Windows 会提示未知发布者）。
- CLI/daemon：`BridgeDeck-cli-0.3.1-<platform>-<arch>.*` 或 `BridgeDeck-cli-bundle-0.3.1.zip`。
- 下载页：https://github.com/iorl566/bridgedeck/releases/tag/v0.3.1

## 签名与校验

- `release.json` 使用生产 Ed25519 密钥签名（keyId `c7b5e21301f91a2d`）。
- 下载后可用 `release-public.pem` 校验清单；`SHA256SUMS` 包含全部制品哈希。
