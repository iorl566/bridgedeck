# BridgeDeck 0.3.1

> 2026-11-26。本版本在 0.3.0 冻结工作树上完成“打包轻量化 + 版本升级”，功能面与 0.3.0 保持一致，
> 主要变化在分发形态与可验证性。

## 亮点

- **打包保持自有方式**：发布扩展包继续使用源码树逐文件打包（`tools/build-extension.mjs`，426 文件 /
  zip ≈ 3.6 MB），保留模块边界、便于审核与按文件升级；`tools/verify-extension-package.mjs` 解压校验。
- **版本一致性**：`package.json` / `extension/manifest.json` / `apps/extension` / `dsh-plugin` /
  `wxt.config` / HAR creator 统一为 `0.3.1`；发布前一致性检查（版本/协议/方法面/feature/错误码/制品）全绿。
- **行为级差分基线**：新增 `tools/bsk-differential`，在真实 Edge 上对同一 fixture 跑 10 个任务，
  首份结果 **9/10 equal**（唯一差异：`read` 是否返回输入框当前值），详见 `docs/BEHAVIOR-DIFF-BSK.md`。
- **命令面/质量不变**：单测 5,051、CLI 404、MCP 216、Python 181、TS 649；真实 Edge E2E 222 条
  （JS 222/222；TS 侧受环境抖动影响，最好 220/222）。

## 安装

- 扩展包：`dist/BridgeDeck-extension-0.3.1.zip`（加载已解压的扩展）。
- Windows 安装器：`dist/BridgeDeckSetup-0.3.1.exe`（本仓库当前为本机验证签名，正式分发需按 runbook 重签）。
- CLI/daemon：`dist/BridgeDeck-cli-0.3.1-<platform>-<arch>.*` 或 `dist/BridgeDeck-cli-bundle-0.3.1.zip`。

## 已知事项

- 本工作树的 `dist/` 产物使用**临时验证密钥**签名，仅用于本地链路验证，不可直接对外分发；
  CI 正式发布需生产私钥（详见 `docs/RELEASE-0.3.1-CI-RUNBOOK.md`）。
- TS 产物真实浏览器 E2E 在负载较高机器上偶发截图/CDP 抖动，属环境 flake（JS 基线 222/222 稳定）。
- 按发布策略，本版本暂不上传 GitHub Release 与 Edge 商店。
