# BridgeDeck 0.1.5

0.1.5 是能力与安全边界刷新。GitHub 发布；Edge 商店的 0.1.3 仍在审核，本版本不重新提交 Edge。

## 新增

- **扩展侧页面策略**：`chrome://`、`edge://`、扩展页、devtools、`view-source:`、`javascript:` 在注入/导航前直接拒绝（`E_FORBIDDEN`），不依赖 daemon 的会话范围。
- **6 位本机配对码**：`bridge daemon pair` 同时输出链接和配对码；扩展“连接设置”需要填码，只拿到链接不能完成配对。
- **候选动作**：`bridge observe --actions` 返回 `@eN + action + role + name`，先选再执行。
- **动作缓存/自愈**：`observe --actions` 记住 ref 语义；`click/fill/select --heal` 在 ref 失效时重新观察并按 action+role+name 找回目标。
- **敏感数据**：`fill --secret NAME` 从 `BB_SECRET_NAME` 取值；`{{secret:NAME}}` 占位符；输出 `actual_value` 自动脱敏。
- **域名策略**：`session start --allow-domains a,b --deny-domains x,y`，策略外导航返回 `E_FORBIDDEN`。
- **性能结论**：`bridge debug performance --insight` 把指标转成 TTFB/LCP/CLS/长任务等可执行结论。
- **recipe 块**：`{type:"if",when:{urlIncludes|urlMatches},then,else}`、`{type:"loop",times,steps}`、`{type:"human",reason,timeoutMs}`；风险步骤递归审批。

## 审查修复

- `frame-cdp` 关闭 `Target.setAutoAttach`/`Accessibility`，所有 frame/AX 读取 5s 超时。
- DSH 技能注册失败不阻断 `browser_*` 工具。
- 生成物 LF 归一化；发布 workflow 仅 `workflow_dispatch`；release.json 未签名（未配置密钥）。
