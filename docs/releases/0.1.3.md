# 0.1.3

本次为扩展商店补丁版本，在 0.1.2 基础上同步最新的观察与运行时能力。

## 新增与增强

- **观察事实层**：DOMSnapshot 几何/可见性/`domClickable`/`domPaintOrder`；表单值（密码遮蔽）与 `formStateStale`；表格 `row/col/header`；`blockingLayers`/`underBlockingLayer`。
- **无 ref 元素**：`unmappedAx` + `click-backend`；page-lib 失败时自动 AX 兜底。
- **备用采集器**：`observe --pipeline ax` 完全走 AX + DOMSnapshot；`--compare-ax` 返回覆盖率与耗时基线。
- **可恢复会话**：`session.start_tracked` + token 幂等；`effect_state` 贯穿成功/前置失败/未知。
- **插件直连 daemon**：`browser_observe/status/session_start|stop/navigate/act/read/screenshot/tab*/window` 优先 `/rpc`，失败再回退 CLI。
- **协议 1.9**：`--unverified`、能力位协商与 minor 偏斜标注。
