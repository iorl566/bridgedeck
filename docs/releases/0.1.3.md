# 0.1.3

本次为 0.1.3 的刷新版本（版本号不变），补齐扩展采集、工程结构与平台支持。

## 扩展与采集

- 持久录制内容脚本：文本 diff、媒体进度、hover 停留、文件/拖拽、SPA 导航、录制器导航恢复；
- iframe 跨 frame popup 归属：`token` + `parentFrameId`；
- 录制默认过滤 Agent 动作，`record start --include-agent` 可保留；
- 新增系统通知、`idle` 重连、Agent 标签组、Daemon 升级提示；
- all-frames 人工输入状态：字段、媒体、焦点、编辑态、文本快照；
- 权限移除 `webRequest`，新增 `notifications`、`idle`、`tabGroups`。

## 工程

- `actions.js` 拆为 observation / interaction / navigation / waits / read / shadow 等模块，仅保留统一出口；
- 生成式协议：`tools/gen-protocol.mjs` → `extension/src/generated/protocol.js`，protocol-check 增加漂移门禁；
- UI 共享模块、按钮全量静态审计、呼吸框动画与交互一致性对齐；
- 弹窗裁切、版本显示、当前任务跳转、设置保存状态修复。

## 平台

- CLI/daemon：Windows x64、macOS arm64/x64、Linux x64/arm64；
- Edge：Windows 真实 E2E；
- Chrome：Windows 通过 CDP `Extensions.loadUnpacked` 完成真实 E2E；
- macOS/Linux 浏览器端仍无等价自动验收。

## 验证

- 单测 1003/1003、CLI 155/155；
- Edge 145/147、Chrome 145/147（各 2 项按借用确认策略跳过）；
- protocol-check、UI 按钮静态审计（80/80 已绑定）通过。

## 反爬（2026-11-16 二次刷新）

同一版本号的又一次刷新，内容变了，版本号按计划保持不变。

- **移除 MAIN world 常驻注入**：`injected/main-console.js` 不再由 manifest 静态注册，改为 `src/page-hooks.js` 按需注入，并提供 `injected/main-console-restore.js` 完整还原原生 `console`/`fetch`/`XHR`；
- `console` 命令语义变化：只返回钩子安装之后的条目（早期日志用 `debug` 采集，CDP 会回放缓存）；
- `data-bb-command-id` 只在钩子生效期间写入 `<html>`，平时不留标记；
- 陈旧 CDP 会话自愈：`send` 遇 "Debugger is not attached" 时重挂并补回焦点仿真后重试一次；
- 新增防回归单测 `tests/unit/anti-bot-injection.test.mjs`（manifest 不许出现 MAIN world 脚本）。

复核（Edge 157，真实 IP）：pixelscan `tamperedFunctions` 转 Clear、browserscan `CDP` 转 Normal、fingerprint-scan 60/100 → 0/100；rebrowser 仅剩 Edge 固有的 `useragent` 一项红。详见 [反爬总报告](../ANTI-BOT-REPORT.md)。

## 驱动通道矩阵（2026-11-16 第三次刷新）

同一版本号的第三次刷新：验证码驱动通道矩阵按题型换手势重跑（3 轮 × 6 题型），并修掉一个长按时序缺陷。

- `extension/injected/page-lib.js` → **v43**（`PAGE_LIB_VERSION` 同步 43）：`actionDrag` 的 `holdMs` 原来在 `pointerdown` **之前** sleep，实际只是"先等一会儿再按下"，控件收到 0 长按；现在改为按下之后保持按住，再开始移动。可信路径（`--trusted`）本来就是正确顺序。
- 矩阵结果：滑拼 / 刮刮乐 / 圆柱 / **按压旋转** / **点击拼图** 5 题 `channel-verified`，双滑块 `never-reacted`（手柄可驱动，错位不判定）；基线 `tests/anti-bot/captcha-drive-baseline.json`。
- 矩阵工具改为按题型配手势（`drag` / `hold` / `points` / `dual`），反馈改为窗口化采样（动作后 300ms 粒度最多 2.4s），并新增合并工具 `tools/merge-captcha-drive.mjs`。

## 能力增强（2026-11-16 第四次刷新）

同一版本号的第四次刷新：本轮补齐的行为层与安全层改动（page-lib v49）。

- **契约**：意图账本结算改读 `error.data.dispatched/effect_state`（确定未派发不再冻结）；`plan` 返回同步观察并兼容 `{method,params}`/`{action,...}`/`{action:{method,params}}` 三种步骤写法；`fill` 返回 `actual_value`（非敏感、截断 200）+ `formatted`；`press` 增加 US 标点物理键码；新增 `--steps-file`。
- **观测**：VOM 增加 `[field: "..."]` 前置标题、`[custom-dropdown: ...]`、连续 ≥3 条只读行折叠；stealth 增加零对比度、`text-indent`、`bg-clip:text` 渐变保留与 `sr-only` 保留；`unchanged` 观察复用（daemon 用缓存补文本）；CLI `--delta` 真正计算行级 patch；虚拟行 `rowAnchor` 校验。
- **输入/会话**：`select` 先校验后滚动、支持 `label` 属性/大小写/歧义候选（`data.available`）；`session start|open --scope` 绑定 caller scope，`BB_SESSION_SCOPE` 兜底；`wait-for-navigation` 读 `pendingUrl` 与 bfcache 恢复（`back/forward` 不再白等 15s）。
- **可靠/安全**：feature 兼容表 + 派发前 preflight；recipe 独占锁 + run 标记（`E_RECIPE_LOCKED`）；账本目标/步骤摘要与 0600；配对服务端证明（`serverProof`）+ `bridge daemon rotate`；输入标记改 `performance.now()` 单调时钟；AX 域 10s 租约；浮层最小化按会话保存；popup 连接设置常显 + 未配对警告；`logs --follow`/`--quiet`/`--verbose`。
- **执行模型**：`plan` 改为 daemon 逐步骤执行——每一步独立账本记录与结算，首步失败即停；precondition 失败记 `effect_state:none` 不冻结标签页。观察/截图返回短别名 `oN`/`cN`，可直接写 `--observation o2`、`--baseline o1`、`--capture c1`。
- **增量与浮层**：行级补丁支持新增/删除行（`structural-text`），CLI 输出 `+/-` 行并本地合并；接管浮层最小化状态随 `showTakeover` 传入页面脚本，跨导航保留。
- **观测与恢复**：page-lib 增加 mutation log——无 DOM 变更/输入交互时跳过 VOM 重建；只有文本节点变化时用 `lineMap` 只重渲染最近祖先子树（`incremental:true`），结构变化仍回退整页；`bridge ui --diagnostics` 输出页面自检与 AX 域租约；debugger 软分离或外部 detach 后重挂时恢复持有者 features 与焦点仿真。
- **观察新鲜度**：mutation log 同时观察 `attributes`，并把 `scroll/resize` 记为 layout 变化；`unchanged` 快路径只在没有 DOM/属性/布局/交互变化时使用，属性变化（如 `aria-expanded`）会重新计算 VOM；增量补丁仍只接受纯 `characterData`。新增 `tests/unit/mutation-summary.test.mjs` 覆盖这组策略。
- **多 frame 与恢复**：同源 iframe 的文档也纳入 mutation 观察；多 frame 页面的 `--delta` 统一用合并基线计算 patch，避免把其它 frame 从合并文本里删掉。`debugger.simulate-detach` 可模拟浏览器侧 detach，实测重挂后焦点仿真恢复（`document.hasFocus()` 仍为 true）。
- **工程清理**：删除未使用的 `action-guard`；导航/刷新时清空扩展侧观察基线；本地 `observations/` 缓存按 7 天 TTL + 300 个文件上限自动清理（每 10 分钟最多扫一次）。
- **跨源兜底**：注入失败的 frame（跨源/沙箱/受限）改用 CDP `Target.setAutoAttach` 发现 OOPIF，再按 target 采集 AX 树渲染成只读文本；不生成可动作 ref，`--cdp-frames` 可强制诊断。新增 `tests/unit/frame-cdp.test.mjs` 覆盖 AX 归一化。
