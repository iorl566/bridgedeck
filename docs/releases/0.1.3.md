# 0.1.3

本次为 0.1.3 的刷新版本（版本号不变），补齐扩展采集、工程结构与平台支持。

## 扩展与采集

- 持久录制内容脚本：文本 diff、媒体进度、hover 停留、文件/拖拽、SPA 导航、录制器导航恢复；
- iframe 跨 frame popup 归属：`token` + `parentFrameId`；
- 录制默认过滤 Agent 动作，`record start --include-agent` 可保留；
- 新增系统通知、`idle` 重连、Agent 标签组、Daemon 升级提示；
- all-frames 人工输入状态：字段、媒体、焦点、编辑态、文本快照；
- 权限移除 `webRequest`，新增 `notifications`、`idle`、`tabGroups`。

## 工程

- `actions.js` 拆为 observation / interaction / navigation / waits / read / shadow 等模块，仅保留统一出口；
- 生成式协议：`tools/gen-protocol.mjs` → `extension/src/generated/protocol.js`，protocol-check 增加漂移门禁；
- UI 共享模块、按钮全量静态审计、呼吸框与 BSK 0.5.0 逻辑对齐；
- 弹窗裁切、版本显示、当前任务跳转、设置保存状态修复。

## 平台

- CLI/daemon：Windows x64、macOS arm64/x64、Linux x64/arm64；
- Edge：Windows 真实 E2E；
- Chrome：Windows 通过 CDP `Extensions.loadUnpacked` 完成真实 E2E；
- macOS/Linux 浏览器端仍无等价自动验收。

## 验证

- 单测 955/955、CLI 155/155；
- Edge 145/147、Chrome 145/147（各 2 项按借用确认策略跳过）；
- protocol-check、UI 按钮静态审计（80/80 已绑定）通过。
