# BridgeDeck 0.1.10

0.1.10 是 0.1.9 之后的 P0 能力版本：分层观察、复合 ref 元数据、跨帧投影，以及继续全绿的 fail-closed 动作契约。

## 新增

- `observe` 返回分层文档：
  - `layers`: L1 当前文档 + L2 遮挡/弹窗层（role、name、coverage、bounds）；
  - `blockingLayers` 与 `--ax --facts` 的交叉检查继续保留；
- `observe` 返回 `refDetails`：
  - `@eN` + `backendNodeId` + `frameId` + `documentId` + `revision`；
  - 供调用方判断 ref 是否属于当前文档/代数；
- `observe` 返回 `tokenEstimate`；
- frame alias 携带 URL/documentId；
- trusted frame click 先做 **owner-quad 投影**，投影失败才回退 frame 内 page-lib 点击；
- 投影路径使用输入租约并在 finally 释放。
