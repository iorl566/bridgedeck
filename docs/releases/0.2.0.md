# BridgeDeck 0.2.0

0.2.0 是深度控制版本：真实 OOPIF、嵌套 frame 投影、复合 RefKey、record per-document、cooperation 状态与真实浏览器 eval。

## 核心能力

- **RefKey / CDP 路由**
  - `backendNodeId + frameId + cdpSessionId + documentId + revision`；
  - 主文档 ref 自动补 backendNodeId，click 走 CDP `DOM.resolveNode`；
  - E2E 断言 `via=cdp-backend`。
- **OOPIF / 嵌套投影**
  - 同源嵌套 owner 链；
  - 真正跨源 OOPIF：`Page.getFrameTree` + `DOM.getFrameOwner`；
  - E2E：`23p2`（frame-projected）、`23p3`（cdp-frame-owner）。
- **VOM 视觉**
  - 分层文档 L1/L2；
  - `visualRegions` + `visualRefs` 坐标映射。
- **Cooperation**
  - FrameState 计数器；
  - 2-rAF capture suppression；
  - authority generation/revision/context/observation。
- **Record**
  - per-document Port；
  - 事件携带 `documentId/frameUrl/boundary`。
- **Action Receipt**
  - 成功/失败动作都带 effect/revision/recovery。
- **Replay-safe timeline**
  - document/frame/revision 边界；跨边界拒绝重放。
- **Eval**
  - 12-case 真实 Edge corpus；
  - tri-state oracle；缺失 case = unverified。
