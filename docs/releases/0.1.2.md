# 0.1.2

本次版本集中修复「Agent 窗口与共享控制」的可靠性问题，并补齐若干易用性细节。协议版本仍为 **1.8**。

## 新增

- **每任务一个专属 Agent 窗口**：新增 `window.newAgent` / `window.close`，`session start` 为每个会话新建独立窗口，`session stop` 连带关闭自己的窗口；`tab.new` 默认落在本会话窗口内。
- **会话控制标签（真正生效）**：浮层显示 agent 名称、项目、会话 ID 与颜色。此前 `showTakeover` 注入时丢掉了 `controller`，品牌名永远是默认值；现在 CLI / DSH 插件传入的 `--agent-name --project --controller-color` 都会显示。
- **技能安装**：`install-skill` 支持 `pi`、`hermes`、`kimi-code`；新增 `daemon restart`；`install-skill --mcp` 可一键写入 Codex / Cursor / Claude 的 MCP 配置。
- **远程配对更简单**：远程模式只保留一个「粘贴配对链接」输入，地址与 token 收进「高级」折叠区；新增 `bridge settings set --control-hint on|off`。
- **预写意图账本**：所有变异操作先在本机落一条脱敏记录（只记方法名、参数键名、session/tab id）；超时、取消或断连后同标签页的新变异操作会被拦截，直到执行 `bridge ledger resolve <id>`。只读与诊断命令不受影响；`cooperate sync` 成功后会按标签页自动和解历史未知意图。详见 [意图账本](../intent-ledger.md)。
- **MCP 增加 plan 工具**：`browser_plan` 一次串行执行多个已决定的动作，首个未完成的步骤即停止、不重试。
- **recipe 分级回放**：只读/可逆步骤（observe、screenshot、scroll-to、wait-* 等）无需审批即可回放；包含 click/fill/press 等风险步骤时要求 `recipe approve --confirm-human`。
- **观察文本增量**：`observe --delta` 先在扩展侧缓存整页观察并返回 `observationId`，之后 `--delta --baseline <id>` 只返回变化行（行级补丁）；行数/ref 序列变化、基线失效或本地无缓存时自动回退整页。详见 [观察增量](../observation-delta.md)。
- **配对与设备可见性**：`pair create --replace` 可直接作废旧配对码重建；新增 `pair devices` 查看已连接的远程设备。
- **录制停止更稳**：操作录制结束时持久化失败会重试一次并裁剪，保留已捕获的步骤，不再整段丢失。
- **fill 热路径**：合并 trusted fill 的 CDP 设置调用（并行 + 仅后台标签才前置），鼠标/键盘事件改为流水线发送、聚焦状态缓存 1s、焦点仿真清理不再阻塞返回；新增 `tools/bench-fill.mjs` 基准（直接 RPC：IPC 基线约 9ms，fill 中位约 107ms，较优化前的约 117ms 再降约 9%）。
- **配对设备面板**：弹窗新增「配对设备」列表与撤销（单个/全部），配对指引按浏览器语言提供中（简/繁）、英、日、韩、法、德、西、意、葡 10 种文案。
- **`wait-for-navigation` 宽限期**：页面刚 complete 后若紧接着开始新的主导航（重定向/SPA 跳转），只有在一段安静窗口（默认 300ms，可用 `graceMs` 传入）内 URL 与状态稳定才算到达；返回的是最终 URL。参考 0.5.0 的 `DEFAULT_NAVIGATION_START_GRACE_MS`。
- **VOM `<select>` 选项内联**：观察结果列出最多 10 个选项（`[options: bj="北京" | sh="上海"* | ...]`，`*` 为选中项）；`select` 支持按可见 label 选择，重复 label 返回 `E_OPTION_AMBIGUOUS` 并给出可用 value，未命中返回 `E_OPTION_NOT_FOUND` 并列出候选，禁用控件在派发前拒绝。
- **fill 3 步快路径**：页面内聚焦并选中 → CDP `insertText` → 页面内校验（返回 `actualValue/formatted`），不适合的控件自动回退原 trustedFill。
- **动作前开销栅栏**：没有打开浮层时跳过 `withOverlaysHidden`（原实现每次动作都执行两次 `executeScript` + 固定 80ms 等待）；直接 RPC 实测 fill 中位 **107ms → 18.5ms（约 -83%）**，有接管浮层时仍走隐藏/恢复路径。
- **提示注入剥离**：观察时跳过非交互的视觉隐藏子树（`opacity < 0.05`、字号 ≤ 1.5px、尺寸 < 2px、离屏 ±5000px），保留按钮/链接/输入等可交互控件与 `.sr-only` 可访问标签。
- **账本"不误冻结"**：派发前就失败的变异操作（参数不合法、目标不存在、`option_not_found`、禁用控件等，带 `effect_state:none`/`dispatched:false` 语义）记为 failed，不再要求 `ledger resolve`。
- **get-html 保护上下文**：`get-html --json --out <file>` 只返回 `path/written_bytes/byte_size/truncated`，不再把整页 HTML 打进模型上下文；不带 `--out` 时行为不变。

## 修复

- **Agent 窗口被页面守卫吞掉**：建窗后 `tabs.onCreated` 与 `agentWindowId` 登记的竞态会让守卫把新窗口的唯一标签页挪回用户窗口，导致「Agent 跑在用户当前页面里」。现在按窗口维度登记 + await 后二次校验 + 单标签窗口放行。
- **呼吸边框更清楚**：页面控制指示从 `2px@0.4` 的浅色内描边升级为 `3px@0.95` 实心蓝环 + `18px@0.55` 内光晕，并保留 `18px@0.10` 的常驻底光；呼吸动画改为 3 秒脉冲 2 次后停在 60% 不透明度，减少「看不出来正被控制」的情况。
- **「控制提示」开关真正生效**：此前该开关只写设置、没有任何界面效果。现在关闭会立即移除所有页面的接管浮层与呼吸边框，再次打开立即恢复。
- **远程配对不再弹回本机**：弹窗里的模式选择不再被状态轮询覆盖；同时修复弹窗自测会把「借用前确认 / 人工协助 / 控制提示」三个开关留在关闭状态的问题。
- **`session start` 默认焦点**：改为默认聚焦新建的独立窗口，`--no-focus` 才后台开窗。
- **借用前确认不可被 CLI 关闭**：`settings set --borrow-confirm` 现返回 `E_FORBIDDEN`；扩展侧 `settings.set` 同样拒绝 daemon/CLI 来源的 `borrowConfirm`；`tab.borrow` 不再接受参数降级，只听浏览器里保存的设置。
- **敏感字段遮蔽补齐**：`value` 属性读取也返回 `********`（密码 / `current-password` / `new-password` / `one-time-code` / `cc-*` 及切到 `type=text` 的密码框）。
- **`reload` 后会话全部失效**：`instanceId` 改存 `chrome.storage.local`，同一浏览器 reload / 重启后沿用同一实例，daemon 可恢复既有会话。
- **`install-skill --mcp`**：`mcp` 之前未注册进 CLI 布尔 flag，功能存在但不可用，已修复。
- **坐标点击**：`click-point` 等待滚动停稳（120ms 静止 / 最长 800ms），避免按旧坐标点到别的元素。
- **连接日志降噪**：daemon 不在时每轮扫描只输出一条摘要，不再刷 10 行。
