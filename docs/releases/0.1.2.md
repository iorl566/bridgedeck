# 0.1.2

本次版本集中修复「Agent 窗口与共享控制」的可靠性问题，并补齐若干易用性细节。协议版本升级为 **1.9**（兼容 1.8 扩展）。

## 2026-11-15 补充（协议 1.9 与观察增强）

- **协议 1.9**：hello/hello-ack/status/`browsers` 统一返回 `1.9`；同一 major 内允许 minor 偏斜（1.7/1.8 扩展仍可连接），`browsers` 新增 `protocolSkew` 标注方向；不兼容 major 仍拒绝。
- **`evaluate --unverified`**：跳过观察/上下文一致性校验执行脚本，控制权、暂停、会话/标签页归属仍然生效；结果带 `verified:false`；不能与 `--expect/--depends-on/--observation` 同用。需要扩展协议 1.9（`unverified` 能力），旧扩展返回 `E_UNSUPPORTED_CAPABILITY`。
- **`open --observe`**：一次调用完成建会话 + 导航 + 观察，返回 `sessionId/url/title/observation`。
- **协议能力**：`unverified`、`dom-read` 加入扩展与 daemon 的 `capabilities`；CLI/MCP/SDK/DSH 插件/skill 同步 `unverified` 参数。
- **回归**：单测 908/908、CLI 145/145、MCP 10/10、DSH 插件 24/24、protocol-check 全绿、真实 Edge E2E 131/133（2 项按借用确认策略跳过，协议协商 `protocol=1.9`）。
- **修复**：`screenshot --full-page` 在无 `--mode` 时因对 `const mode` 赋值而从不生效（Bun 解析器直接报错）；现在 `--full-page`/`--full` 都正确映射到 `auto` 整页截图。
- **修复（并发 attach）**：会话预挂 CDP（`armTab`）与 `dialog.arm` 同时 attach 同一 tab 时，第二个 `chrome.debugger.attach` 会因 “Another debugger is already attached” 失败，导致对话框拦截未挂载、`confirm()` 阻塞 click 到 60s 超时。现在按 tab 合并并发 attach（attach-in-flight promise），E2E 对话框步骤稳定通过。
- **read/extract 证据护栏**：会话标签页读取前后校验主文档身份（frameId + documentElement backendNodeId），读取期间发生导航/重渲染会返回 `E_CONTEXT_STALE`，不把新旧文档混合的数据交给调用方。
- **可恢复会话启动**：`session start --request-id <expiry>:<id>` 走 `session.start_tracked`，daemon 预写 `session-starts.json`；同 token 重试返回同一会话（`reused:true`），过期/格式错误拒绝，进行中返回 `E_START_PENDING`。新增 `session prepare|claim|cancel|request` 生命周期：prepared → starting → ready → claimed，取消留下 `cancelled` 墓碑；DSH 插件新建窗口时自动生成 token 并在超时后重试一次，避免回复丢失留下孤儿窗口。
- **observe --facts**：DOMSnapshot 采集 `bounds/visible/clickable` 并按 backendNodeId 映射到 `--ax`/`--vom` 节点；`--vom --facts` 无需 `--ax`。CLI/MCP/DSH 插件均暴露该开关，未开启时零附加成本。
- **DSH 插件启动所有权日志**：新建会话前先把 token 写入 `$BB_HOME/dsh-starts.json`；成功后记录 sessionId/tabId/windowId。插件重启时对过期 `starting` 记录用同一 token 向 daemon 查询：ready 的孤儿会话自动 stop 并标记 recovered，其余标记 stale；崩溃/超时不再留下无法认领的 Agent 窗口。
- **effect_state**：变异方法成功返回 `result.effectState="committed"`；前置校验失败（expect/depends/遮挡）返回 `error.data.effect_state="none"` 且 `dispatched:false`；超时/断连等无法证明的失败返回 `"unknown"`，提示调用方不要自动重放。
- **request-help 完成条件**：`request-help --until '[{"kind":"selector_exists","selector":"#done"}]'` 支持 `selector_exists`/`selector_visible`/`text_exists`/`url_contains`（最多 10 条）；用户完成页面操作后自动返回 `done`，不必再点协助卡片。
- **observe --facts 文本修正**：DOMSnapshot 判定不可见但语义树仍带 ref 的行，末尾追加 `[dom-hidden]`；结果附 `hiddenRefs` 与 `facts.hiddenRefs` 数量。
- **observe --fallback-ax（AX 兜底）**：page-lib 观察失败时自动用 CDP AX 树 + DOMSnapshot 几何渲染降级语义树（无 ref，标记 `fallback:"ax"`）；也可显式 `--fallback-ax` 强制。自动兜底不可用时仍返回原始错误。
- **未映射 AX 交互元素**：`observe --ax --vom` 额外返回 AX 中未映射到 ref 的可交互节点（closed shadow DOM 等），带几何、标注“仅供定位”，并过滤 BridgeDeck 自身浮层按钮。
- **`click-backend`**：按 `backendNodeId` 点击无 ref 元素；动作前做可见性/遮挡检查，用 CDP 原生鼠标事件派发（`isTrusted=true`），失败返回 `E_NOT_FOUND`/`E_NOT_ACTIONABLE`/`E_OCCLUDED` 且 `dispatched:false`；计入 agent 输入窗口，避免误触发人工接管暂停。
- **observe --facts 映射优化**：`--vom --facts` 直接从 DOMSnapshot 的 `data-bb-vom` 属性解析 backendNodeId，省掉一次 `DOM.getDocument(pierce)`；大数据页观察更快，`facts.vomMatched` 语义不变。
- **observe --facts 表单事实**：从 DOMSnapshot 解出 `inputValue`/`inputChecked`/`optionSelected`，节点附 `domValue`/`domChecked`/`domSelected`；与 page-lib 采样不一致时标 `formStateStale`。密码/sensitive autocomplete 值统一遮盖为 `********`，不进入结果。
- **observe 表格结构事实**：`--ax --vom` 时按 AX 层级给单元格附 `table:{row,col,header,headerRow}`，并返回 `tables:[{role,name,rowCount,colCount,headers}]` 汇总。
- **observe --facts 绘制顺序**：节点附 DOMSnapshot `domPaintOrder`，可与 page-lib 的 `paintOrder` 交叉校验叠放顺序。
- **阻挡层事实**：`--ax --vom --facts` 时返回 `blockingLayers:[{role,name,bounds,coverage}]`，识别覆盖视口 ≥25% 的可见 dialog/alertdialog，作为 page-lib blocking 的独立交叉检查；落在矩形内的节点带 `underBlockingLayer`。
- **可见性/点击语义修正**：`clickable` 仍以 page-lib 命中测试为准，DOMSnapshot 值改为 `domClickable`；`visible=false` 与 `hitTest=self` 矛盾时标 `visibilityStale`。
- **观察双跑校验**：`observe --compare-ax` 返回 `pipelineCompare`（page-lib / AX 的耗时、字符、行数、交互元素覆盖率），用于采集器替换前的量化基线。
- **备用采集器**：`observe --pipeline ax` 完全走 AX + DOMSnapshot，返回 `pipeline:"ax"`、`refs:0` 与结构化节点（含几何/可见性/表格），用于校验或 page-lib 不可用时的降级。
- **DSH 插件直连 daemon**：`browser_observe/status/session_start|stop/navigate/act/read/screenshot/tab*/window` 优先 POST `/rpc`（读 daemon.json + token），session 启动走 `session.start_tracked` 并保留插件 journal；仅在请求未发出时回退 CLI。实测 observe warm 9ms、session.start 144ms、read 5ms、focus 27ms、截图 194ms、tab.list 14ms。设置 `BB_PLUGIN_DIRECT_RPC=0` 可关闭。
- **插件直连冒烟**：新增 `tests/plugin/smoke.mjs`（真实 Edge + 真实 daemon，禁用 CLI 兜底），覆盖 11 项并验证 0 次 CLI 回退。
- **性能**：扩展改为按 tab 常驻 CDP 驱动（attach 一次、75s 空闲软分离、network/dialog/session 等长任务租约），evaluate 走 `Runtime.evaluate`、截图不再每次 attach；会话标签页启用 `Emulation.setFocusEmulationEnabled`，可信输入在后台 Agent Window 直接派发、不再切换前台 tab/窗口。`session stop` 清理并行化并跳过关标签时的不必要等待（299ms → ~126ms）；`session start` 的 dialog.arm/control-hint 不阻塞、窗口登记并行、焦点恢复异步（345ms → ~269ms）；导航后浮层不阻塞返回；`wait-for-navigation` 已 complete 时快速返回（轮询 50ms、grace 60ms）；CLI 的 update/trace/debug/recipe/schema/embedded-skill 改为按需加载；CLI 命中存活 daemon 时跳过 `/health` 预检。

## 新增

- **每任务一个专属 Agent 窗口**：新增 `window.newAgent` / `window.close`，`session start` 为每个会话新建独立窗口，`session stop` 连带关闭自己的窗口；`tab.new` 默认落在本会话窗口内。
- **会话控制标签（真正生效）**：浮层显示 agent 名称、项目、会话 ID 与颜色。此前 `showTakeover` 注入时丢掉了 `controller`，品牌名永远是默认值；现在 CLI / DSH 插件传入的 `--agent-name --project --controller-color` 都会显示。
- **技能安装**：`install-skill` 支持 `pi`、`hermes`、`kimi-code`；新增 `daemon restart`；`install-skill --mcp` 可一键写入 Codex / Cursor / Claude 的 MCP 配置。
- **远程配对更简单**：远程模式只保留一个「粘贴配对链接」输入，地址与 token 收进「高级」折叠区；新增 `bridge settings set --control-hint on|off`。
- **预写意图账本**：所有变异操作先在本机落一条脱敏记录（只记方法名、参数键名、session/tab id）；超时、取消或断连后同标签页的新变异操作会被拦截，直到执行 `bridge ledger resolve <id>`。只读与诊断命令不受影响；`cooperate sync` 成功后会按标签页自动和解历史未知意图。详见 [意图账本](../intent-ledger.md)。
- **MCP 增加 plan 工具**：`browser_plan` 一次串行执行多个已决定的动作，首个未完成的步骤即停止、不重试。
- **recipe 分级回放**：只读/可逆步骤（observe、screenshot、scroll-to、wait-* 等）无需审批即可回放；包含 click/fill/press 等风险步骤时要求 `recipe approve --confirm-human`。
- **观察文本增量**：`observe --delta` 先在扩展侧缓存整页观察并返回 `observationId`，之后 `--delta --baseline <id>` 只返回变化行（行级补丁）；行数/ref 序列变化、基线失效或本地无缓存时自动回退整页。详见 [观察增量](../observation-delta.md)。
- **配对与设备可见性**：`pair create --replace` 可直接作废旧配对码重建；新增 `pair devices` 查看已连接的远程设备。
- **录制停止更稳**：操作录制结束时持久化失败会重试一次并裁剪，保留已捕获的步骤，不再整段丢失。
- **fill 热路径**：合并 trusted fill 的 CDP 设置调用（并行 + 仅后台标签才前置），鼠标/键盘事件改为流水线发送、聚焦状态缓存 1s、焦点仿真清理不再阻塞返回；新增 `tools/bench-fill.mjs` 基准（直接 RPC：IPC 基线约 9ms，fill 中位约 107ms，较优化前的约 117ms 再降约 9%）。
- **配对设备面板**：弹窗新增「配对设备」列表与撤销（单个/全部），配对指引按浏览器语言提供中（简/繁）、英、日、韩、法、德、西、意、葡 10 种文案。
- **`wait-for-navigation` 宽限期**：页面刚 complete 后若紧接着开始新的主导航（重定向/SPA 跳转），只有在一段安静窗口（默认 300ms，可用 `graceMs` 传入）内 URL 与状态稳定才算到达；返回的是最终 URL。
- **VOM `<select>` 选项内联**：观察结果列出最多 10 个选项（`[options: bj="北京" | sh="上海"* | ...]`，`*` 为选中项）；`select` 支持按可见 label 选择，重复 label 返回 `E_OPTION_AMBIGUOUS` 并给出可用 value，未命中返回 `E_OPTION_NOT_FOUND` 并列出候选，禁用控件在派发前拒绝。
- **fill 3 步快路径**：页面内聚焦并选中 → CDP `insertText` → 页面内校验（返回 `actualValue/formatted`），不适合的控件自动回退原 trustedFill。
- **动作前开销栅栏**：没有打开浮层时跳过 `withOverlaysHidden`（原实现每次动作都执行两次 `executeScript` + 固定 80ms 等待）；直接 RPC 实测 fill 中位 **107ms → 18.5ms（约 -83%）**，有接管浮层时仍走隐藏/恢复路径。
- **提示注入剥离**：观察时跳过非交互的视觉隐藏子树（`opacity < 0.05`、字号 ≤ 1.5px、尺寸 < 2px、离屏 ±5000px），保留按钮/链接/输入等可交互控件与 `.sr-only` 可访问标签。
- **账本"不误冻结"**：派发前就失败的变异操作（参数不合法、目标不存在、`option_not_found`、禁用控件等，带 `effect_state:none`/`dispatched:false` 语义）记为 failed，不再要求 `ledger resolve`。
- **get-html 保护上下文**：`get-html --json --out <file>` 只返回 `path/written_bytes/byte_size/truncated`，不再把整页 HTML 打进模型上下文；不带 `--out` 时行为不变。

## 修复

- **严格 CSP 站点上的 `evaluate`**：GitHub、Bing 等 `script-src` 不含 `unsafe-eval` 的页面会拒绝主世界 `eval`（`E_JS_ERROR: ... Content Security Policy`）。现在捕获该错误后回退到 CDP `Runtime.evaluate`（用完分离调试器），普通页面仍走原注入路径；新增 5 项单测，真实 Edge 上 Bing/GitHub 恢复。见 [9 站实测](../SITE-BENCH-BRIDGEDECK-1.9.md)。
- **Agent 窗口被页面守卫吞掉**：建窗后 `tabs.onCreated` 与 `agentWindowId` 登记的竞态会让守卫把新窗口的唯一标签页挪回用户窗口，导致「Agent 跑在用户当前页面里」。现在按窗口维度登记 + await 后二次校验 + 单标签窗口放行。
- **呼吸边框更清楚**：页面控制指示从 `2px@0.4` 的浅色内描边升级为 `3px@0.95` 实心蓝环 + `18px@0.55` 内光晕，并保留 `18px@0.10` 的常驻底光；呼吸动画改为 3 秒脉冲 2 次后停在 60% 不透明度，减少「看不出来正被控制」的情况。
- **「控制提示」开关真正生效**：此前该开关只写设置、没有任何界面效果。现在关闭会立即移除所有页面的接管浮层与呼吸边框，再次打开立即恢复。
- **远程配对不再弹回本机**：弹窗里的模式选择不再被状态轮询覆盖；同时修复弹窗自测会把「借用前确认 / 人工协助 / 控制提示」三个开关留在关闭状态的问题。
- **`session start` 默认焦点**：改为默认聚焦新建的独立窗口，`--no-focus` 才后台开窗。
- **借用前确认不可被 CLI 关闭**：`settings set --borrow-confirm` 现返回 `E_FORBIDDEN`；扩展侧 `settings.set` 同样拒绝 daemon/CLI 来源的 `borrowConfirm`；`tab.borrow` 不再接受参数降级，只听浏览器里保存的设置。
- **敏感字段遮蔽补齐**：`value` 属性读取也返回 `********`（密码 / `current-password` / `new-password` / `one-time-code` / `cc-*` 及切到 `type=text` 的密码框）。
- **`reload` 后会话全部失效**：`instanceId` 改存 `chrome.storage.local`，同一浏览器 reload / 重启后沿用同一实例，daemon 可恢复既有会话。
- **`install-skill --mcp`**：`mcp` 之前未注册进 CLI 布尔 flag，功能存在但不可用，已修复。
- **坐标点击**：`click-point` 等待滚动停稳（120ms 静止 / 最长 800ms），避免按旧坐标点到别的元素。
- **连接日志降噪**：daemon 不在时每轮扫描只输出一条摘要，不再刷 10 行。
