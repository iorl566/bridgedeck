# BridgeDeck 0.1.12

UI 修复版：控制呼吸框匹配控制截图的蓝色呼吸效果，并加强到清晰可见。

## 呼吸框

按控制截图还原蓝色呼吸框并加强：

- 外层柔光：`inset 0 0 28px 8px rgba(122,167,255,.55)`；
- 深层柔光：`inset 0 0 64px 16px rgba(122,167,255,.22)`；
- 呼吸层：`inset 0 0 80px 20px rgba(122,167,255,.55)`；
- 不使用包裹线（无 `inset 0 0 0 3px` 环）；
- 关键帧 `0%,100% opacity .15` → `50% opacity 1`；
- `animation: bbp 3s ease-in-out infinite`；
- 暂停态停止呼吸；
- `prefers-reduced-motion` 关闭动画。
