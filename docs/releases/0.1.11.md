# BridgeDeck 0.1.11

本版是 0.1.10 的 UI 修复版，重点是让“正在被控制”的呼吸框恢复到 0.1.7 时代的清晰度，并修正发布页/README 的版本信息。

## 修复

- 控制呼吸框加强：
  - 外层 `inset 0 0 20px 4px`，透明度 28%；
  - 内层常驻 `inset 0 0 0 3px`，透明度 55%；
  - 呼吸层 `inset 0 0 48px 10px`，透明度 55%；
  - 保留 `prefers-reduced-motion` 关闭动画；
  - 暂停态继续停止呼吸。
- GitHub Releases 的 `latest` 标记修正为当前版本。
- README 的版本号、下载文件名、更新日志链接更新到 0.1.11。
