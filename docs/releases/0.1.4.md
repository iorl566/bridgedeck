# BridgeDeck 0.1.4

0.1.4 是 GitHub 侧的能力与可靠性刷新；Edge 商店的 0.1.3 仍在审核，**本版本不重新提交 Edge**。

## 能力

- **技能斜杠命令**：`bridge install-skill --commands` 为 Claude Code / Codex / Cursor 生成 `/browser-bridge` 命令包装（技能本身仍是 `SKILL.md + references/`）。
- **DSH 内嵌技能**：插件通过 `ctx.skills.register` 注册 `browser-bridge`（agent 作用域），安装插件后不再需要 `install-skill --harness dsh`。
- **跨源 frame 兜底**：注入失败的 frame 用 CDP OOPIF + per-target AX 采集，只读、无动作 ref；`--cdp-frames` 可强制诊断。

## 审查修复

- `frame-cdp` 采集结束关闭 `Target.setAutoAttach` 与 `Accessibility`，所有 frame/AX 读取加 5s 超时，避免 debugger 状态残留或 observe 被卡死。
- DSH 技能注册失败不再阻断 `browser_*` 工具注册，只记录警告。
- 生成物使用 `.gitattributes` 强制 LF，修复 Windows CI 的协议 stale 误报。
- 发布 workflow 改为仅 `workflow_dispatch`，tag 不再自动覆盖 release 资产；`release.json` 未签名（未配置签名密钥），不再发布旧公钥。
